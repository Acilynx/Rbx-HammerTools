# How Roblox lays a Texture on a part face

Measured in Studio with a test image whose u=0 column is black, v=0 row is blue, and image
top-left is marked red, on an 8×8×8 cube and on a 3×5×7 part (the uneven size matters: on a
cube with tile = face size, several wrong rules look identical).

All axes are part-local; the rules rotate with the part (verified on a rotated 3×5×7 part).

| Face | U (image x grows) | V (image y grows) | Tiling starts at |
|---|---|---|---|
| Right (+X) | −Z | −Y | (+X, +Y, +Z) corner |
| Left (−X) | +Z | −Y | (−X, +Y, −Z) |
| Front (−Z) | −X | −Y | (+X, +Y, −Z) |
| Back (+Z) | +X | −Y | (−X, +Y, +Z) |
| Top (+Y) | −X | −Z | (+X, +Y, +Z) |
| Bottom (−Y) | +X | −Z | (−X, −Y, +Z) |
| WedgePart slope (Front) | −X | down the slope, **measured as height** | top-back edge |

Equivalent rule: side faces use reference axis R = Y, top/bottom use R = Z; U = R × n, V = −R.
Every face reads unmirrored from outside.

Properties:

* image x = (u + `OffsetStudsU`) / `StudsPerTileU` (and y likewise)
* `Rotation = 90` turns the image inside each tile but not the tile footprint, so non-square
  tiles get distorted and the phase shifts. Not usable for Hammer rotations.
* A negative `UVScale` has no visible effect on a Texture. Not usable for mirroring.
* So each face instead uses one of the 8 orientations of the source image (transpose, flip x,
  flip y), generated by the importer.

Hammer side of the mapping: texel `s = (P · uaxis) / uscale + uoffset` with `P` in units, `t` likewise
(t runs down the image). The translator expresses s and t as linear functions of the face's
(u, v) in studs; the mapping is representable exactly when s depends only on u and t only on v
(or both swapped).

## Verification

`tests/test_textures.py` checks the code against this table written out literally (not
computed), and checks that the texel Roblox would draw equals Hammer's texel on random 90°
alignments over boxes, rotated boxes and decomposed prisms. Reintroducing the original
precedence bug (`n*h@|n|`) makes 30 of those tests fail.
